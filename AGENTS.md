# Pulse

Build a small, local macOS menu-bar utility using native SwiftUI and AppKit. Keep the main panel compact, text concise, and use system colours, type, controls, keyboard access and SF Symbols. Keep connectors independent of the UI.

Credentials belong in Keychain, user data in Application Support, and demo data must always be labelled. Never commit credentials, private project connection details or cached data. All source connections are read-only; source schema changes and public GitHub publication require separate scope.

Verify meaningful connector, persistence and event-deduplication behavior, then inspect the running native interface. Keep build output and QA evidence local under ignored build/ or .local/.
